Ordinarily, functions follow PascalCase: start with a capital letter and have a capital letter for each new word.
<pre>
AddTableEntry()
DeleteUrl()
OpenFileOrDie()
</pre>
The same naming rule applies to class- and namespace-scope constants that are exposed as part of an API and that are intended to look like functions, because the fact that they're objects rather than functions is an unimportant implementation detail. Accessors and mutators (get and set functions) may be named like variables, in snake_case. These often correspond to actual member variables, but this is not required. For example, int count() and void set_count(int count).
