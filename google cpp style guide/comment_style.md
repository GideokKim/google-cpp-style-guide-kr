# 주석 스타일 (Comment Style)

## 원문 규칙 번역

일관성이 있는 한 // 또는 /* */ 구문을 사용하십시오.

두 구문 모두 허용되지만 //가 훨씬 더 일반적입니다. 댓글을 작성하는 방법과 사용하는 스타일에 일관성을 유지하세요.

---

---

## 이해하기 쉽게 설명하기

이 규칙의 핵심은 댓글을 작성하는 방법과 사용하는 스타일에 일관성을 유지하세요.

실제로 코드를 볼 때는 일관성이 있는 한 // 또는 /* */ 구문을 사용하십시오.

점검할 때는 특히 다음을 확인하세요:

- 두 구문 모두 허용되지만 //가 훨씬 더 일반적입니다.
