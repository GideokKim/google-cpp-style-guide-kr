# 주석 스타일 (Comment Style)

## 원문 규칙 번역

일관성이 있는 한 // 또는 /* */ 구문을 사용하십시오.

두 구문 모두 허용되지만 //가 훨씬 더 일반적입니다. 댓글을 작성하는 방법과 사용하는 스타일에 일관성을 유지하세요.

---

## 이해하기 쉽게 설명하기

주석 스타일 규칙을 적용할 때는 원문 규칙을 문자 그대로 외우기보다, 왜 이 선택이 독자에게 더 명확한지 살펴보면 쉽습니다. 코드 리뷰에서는 이 기능이 호출 지점에서 의도를 숨기지 않는지, 더 단순한 구조로 같은 목적을 달성할 수 없는지, 기존 코드와 섞였을 때 유지보수 비용이 커지지 않는지를 확인하세요.
