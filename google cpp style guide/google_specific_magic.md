# Google 전용 매직 (Google-Specific Magic)

C++ 코드를 더 견고하게 만들기 위해 사용하는 여러 기법과 유틸리티가 있으며, 다른 곳에서 보는 것과 다를 수 있는 C++ 사용 방식도 있습니다. 이 장은 그러한 Google 고유의 도구·관례를 다룹니다.

---

## 이해하기 쉽게 설명하기

Google 전용 매직 섹션은 언어 기능보다 프로젝트 도구와 자동화 관례를 다룹니다. 여기서는 `cpplint`처럼 일관된 스타일을 유지하고 리뷰 부담을 줄이는 도구 사용이 중심입니다.

실무에서는 도구 경고를 단순 취향 지적이 아니라 유지보수 위험을 조기에 알려 주는 신호로 다루면 쉽습니다. 다만 도구가 완벽하지 않으므로 오탐과 미탐 가능성을 이해하고, 필요한 경우 근거를 남겨 예외를 판단해야 합니다.

점검할 때는 특히 다음을 확인하세요:

- 자동화 도구가 잡을 수 있는 스타일 문제를 수동 리뷰에 남겨 두지 않았는가?
- 도구 경고를 무시할 때 명확한 이유가 있는가?
- 프로젝트의 기존 lint 흐름과 새 문서/코드가 충돌하지 않는가?
