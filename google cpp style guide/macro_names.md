# 매크로 이름 (Macro Names)

## 원문 규칙 번역

당신은 실제로 매크로를 정의하지 않을 것입니다. 그렇죠? 그렇게 하면 MY_MACRO_THAT_SCARES_SMALL_CHILDREN_AND_ADULTS_ALIKE 와 같습니다.

매크로 설명을 참조하세요. 일반적으로 매크로는 사용하면 안 됩니다. 그러나 꼭 필요한 경우에는 모두 대문자와 밑줄, 프로젝트별 접두사를 사용하여 이름을 지정해야 합니다.

```cpp
#define MYPROJECT_ROUND(x) ...
```

---

## 이해하기 쉽게 설명하기

매크로 이름 규칙을 적용할 때는 원문 규칙을 문자 그대로 외우기보다, 왜 이 선택이 독자에게 더 명확한지 살펴보면 쉽습니다. 코드 리뷰에서는 이 기능이 호출 지점에서 의도를 숨기지 않는지, 더 단순한 구조로 같은 목적을 달성할 수 없는지, 기존 코드와 섞였을 때 유지보수 비용이 커지지 않는지를 확인하세요.
