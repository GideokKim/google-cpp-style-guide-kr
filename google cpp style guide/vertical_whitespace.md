# 세로 공백 (Vertical Whitespace)

## 원문 규칙 번역

수직 공백을 아껴서 사용하세요. 불필요한 빈 줄은 전체 코드 구조를 보기 어렵게 만듭니다. 독자가 구조를 이해하는 데 도움이 되는 경우에만 빈 줄을 사용하십시오.

코드 블록의 시작이나 끝과 같이 들여쓰기가 이미 명확한 설명을 제공하는 곳에는 빈 줄을 추가하지 마세요. 산문의 단락 나누기와 유사하게 코드를 밀접하게 관련된 덩어리로 분리하려면 빈 줄을 사용하십시오. 문이나 선언 내에서는 일반적으로 줄 길이 제한을 초과하지 않도록 줄 바꿈만 삽입하거나 내용의 일부에만 주석을 첨부합니다.

## 이해하기 쉽게 설명하기

이 규칙의 핵심은 독자가 구조를 이해하는 데 도움이 되는 경우에만 빈 줄을 사용하십시오.

실제로 코드를 볼 때는 문이나 선언 내에서는 일반적으로 줄 길이 제한을 초과하지 않도록 줄 바꿈만 삽입하거나 내용의 일부에만 주석을 첨부합니다.

점검할 때는 특히 다음을 확인하세요:

- 코드 블록의 시작이나 끝과 같이 들여쓰기가 이미 명확한 설명을 제공하는 곳에는 빈 줄을 추가하지 마세요.
- 산문의 단락 나누기와 유사하게 코드를 밀접하게 관련된 덩어리로 분리하려면 빈 줄을 사용하십시오.
