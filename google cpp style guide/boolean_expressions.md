# 불리언 표현식 (Boolean Expressions)

표준 줄 길이보다 긴 불리언 표현식이 있는 경우 줄을 끊는 방법에 일관성을 유지하세요.

이 예에서 논리 AND 연산자는 항상 줄 끝에 있습니다.

```cpp
if (this_one_thing > this_other_thing &&
    a_third_thing == a_fourth_thing &&
    yet_another && last_one) {
  ...
}
```

이 예에서 코드가 래핑되면 && 논리 AND 연산자가 모두 줄 끝에 있습니다. 이는 Google 코드에서 더 일반적이지만 줄 시작 부분에 모든 연산자를 래핑하는 것도 허용됩니다. 적절하게 사용하면 가독성을 높이는 데 큰 도움이 될 수 있으므로 추가 괄호를 신중하게 삽입하세요. 단, 남용하지 않도록 주의하세요. 또한 and 및 compl과 같은 단어 연산자보다는 항상 && 및 ~와 같은 구두점 연산자를 사용해야 합니다.

---

## 이해하기 쉽게 설명하기

### 핵심: 긴 불리언 표현식은 일관되게 줄바꿈

표준 줄 길이를 넘는 불리언 표현식은 줄을 끊는 방식을 일관되게 유지하세요. Google 코드에서는 `&&` 같은 연산자를 **줄 끝**에 두는 것이 더 흔하지만, 모두 줄 **시작**에 두는 것도 허용됩니다(한 코드 안에서 일관되게).

```cpp
if (this_one_thing > this_other_thing &&
    a_third_thing == a_fourth_thing &&
    yet_another && last_one) {
  ...
}
```

### 그 외

- 가독성을 돕는 추가 괄호는 신중히 — 남용은 금물.
- `and`, `compl` 같은 단어 연산자 대신 항상 `&&`, `~` 같은 기호 연산자를 쓰세요.
