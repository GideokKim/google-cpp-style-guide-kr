# Nonmember, Static Member, and Global Functions (Nonmember, Static Member, and Global Functions)

## 원문 규칙 번역

비멤버 함수를 네임스페이스에 배치하는 것을 선호합니다. 완전히 전역 함수를 거의 사용하지 않습니다. 단순히 정적 멤버를 그룹화하기 위해 클래스를 사용하지 마세요. 클래스의 정적 메서드는 일반적으로 클래스 인스턴스 또는 클래스의 정적 데이터와 밀접하게 관련되어 있어야 합니다.

비멤버 및 정적 멤버 함수는 일부 상황에서 유용할 수 있습니다. 비멤버 함수를 네임스페이스에 배치하면 전역 네임스페이스가 오염되는 것을 방지할 수 있습니다.

비멤버 및 정적 멤버 함수는 특히 외부 리소스에 액세스하거나 상당한 종속성이 있는 경우 새 클래스의 멤버로 더 적합할 수 있습니다.

때로는 클래스 인스턴스에 바인딩되지 않은 함수를 정의하는 것이 유용할 수 있습니다. 이러한 함수는 정적 멤버이거나 비멤버 함수일 수 있습니다. 비멤버 함수는 외부 변수에 의존해서는 안 되며 거의 항상 네임스페이스에 존재해야 합니다. 정적 멤버를 그룹화하기 위한 클래스만 생성하지 마세요. 이는 이름에 공통 접두사를 부여하는 것과 다르지 않으며 일반적으로 이러한 그룹화는 불필요합니다.

비멤버 함수를 정의하고 .cc 파일에만 필요한 경우 내부 연결을 사용하여 범위를 제한하세요.
