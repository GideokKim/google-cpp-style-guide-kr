# 비멤버, 정적 멤버, 전역 함수 (Nonmember, Static Member, and Global Functions)

비멤버 함수는 네임스페이스 안에 두는 것을 선호하고, 완전히 전역인 함수는 드물게만 사용하세요. 단순히 정적 멤버를 묶기 위해 클래스를 만들지 마세요. 클래스의 정적 메서드는 일반적으로 그 클래스의 인스턴스나 정적 데이터와 밀접하게 관련되어 있어야 합니다.

비멤버 함수와 정적 멤버 함수는 유용한 경우가 있습니다. 하지만 비멤버 함수를 네임스페이스 안에 두면 전역 네임스페이스 오염을 피할 수 있습니다. 외부 리소스에 접근하거나 의존성이 큰 함수라면 새 클래스의 멤버가 더 적절할 수도 있습니다.

클래스 인스턴스에 묶이지 않는 함수가 필요할 때는 정적 멤버 함수나 비멤버 함수 중 하나를 선택할 수 있습니다. 비멤버 함수는 외부 변수에 의존하지 않아야 하며, 거의 항상 네임스페이스 안에 있어야 합니다. 정적 멤버만 묶으려고 클래스를 만드는 것은 이름에 공통 접두사를 붙이는 것과 크게 다르지 않고 보통 불필요합니다.

비멤버 함수가 해당 `.cc` 파일에서만 필요하다면 내부 연결을 사용해 범위를 제한하세요.

---

## 이해하기 쉽게 설명하기

함수가 어떤 객체의 상태를 읽거나 바꾸지 않는다면 굳이 클래스 멤버일 필요가 없습니다. 하지만 그렇다고 전역 함수로 아무 곳에나 놓으면 이름 충돌과 의존성 문제가 생깁니다. 가장 흔한 선택지는 "관련 네임스페이스 안의 비멤버 함수"입니다.

```cpp
namespace image {

int ClampChannel(int value);

}  // namespace image
```

반대로 `Util` 같은 클래스를 만들고 모든 함수를 `static`으로 넣는 방식은 실제 캡슐화를 제공하지 못합니다. 이름을 묶고 싶다면 네임스페이스가 더 자연스럽습니다.
