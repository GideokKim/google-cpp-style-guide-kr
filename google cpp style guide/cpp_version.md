# C++ 버전

현재 코드는 C++20을 대상으로 해야 하며, 즉 C++23 기능을 사용해서는 안 됩니다. 이 가이드가 대상으로 하는 C++ 버전은 시간이 지남에 따라 (적극적으로) 발전할 것입니다.

비표준 확장(non-standard extension)을 사용하지 마세요.

프로젝트에서 C++17 및 C++20의 기능을 사용하기 전에 다른 환경으로의 이식성을 고려하세요.

---

## 옮긴이 풀이

C++ 버전 규칙은 "최신 기능을 무조건 쓰지 말라"는 뜻이 아니라, 프로젝트가 목표로 하는 표준과 이식성 범위 안에서 코드를 작성하라는 뜻입니다. 현재 기준이 C++20이라면 C++23 기능은 편리해 보여도 다른 빌드 환경에서 깨질 수 있습니다.

새 기능을 쓰기 전에는 팀의 컴파일러, 플랫폼, 의존 라이브러리, 장기 유지보수 계획이 그 기능을 안정적으로 지원하는지 확인해야 합니다.
