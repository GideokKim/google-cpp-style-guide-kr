# 파일 주석 (File Comments)

## 원문 규칙 번역

소스 파일(예: .h 파일)이 여러 사용자 대상 추상화(공통 함수, 관련 클래스 등)를 선언하는 경우 해당 추상화 컬렉션을 설명하는 주석을 포함합니다. 미래의 저자가 거기에 맞지 않는 것이 무엇인지 알 수 있도록 충분한 세부 정보를 포함하십시오. 그러나 개별 추상화에 대한 자세한 문서는 파일 수준이 아닌 해당 추상화에 속합니다.

예를 들어, frobber.h 에 대한 파일 주석을 작성하는 경우 frobber.cc 또는 frobber_test.cc 에 파일 주석을 포함할 필요가 없습니다. 반면에, 연관된 헤더 파일이 없는 Registered_objects.cc에 클래스 컬렉션을 작성하는 경우 Registered_objects.cc에 파일 주석을 포함해야 합니다.

작성자 줄이 있는 파일을 크게 변경한 경우 작성자 줄을 삭제하는 것이 좋습니다. 새 파일에는 일반적으로 저작권 표시나 작성자 라인이 포함되어서는 안 됩니다.

---

## 이해하기 쉽게 설명하기

파일 주석 규칙을 적용할 때는 원문 규칙을 문자 그대로 외우기보다, 왜 이 선택이 독자에게 더 명확한지 살펴보면 쉽습니다. 코드 리뷰에서는 이 기능이 호출 지점에서 의도를 숨기지 않는지, 더 단순한 구조로 같은 목적을 달성할 수 없는지, 기존 코드와 섞였을 때 유지보수 비용이 커지지 않는지를 확인하세요.
