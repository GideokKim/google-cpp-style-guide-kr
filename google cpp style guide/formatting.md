# 형식 지정 (Formatting)

코딩 스타일과 형식은 매우 임의적이지만 모든 사람이 동일한 스타일을 사용하면 프로젝트를 훨씬 쉽게 따라갈 수 있습니다. 개인은 서식 규칙의 모든 측면에 동의하지 않을 수 있고 일부 규칙에 익숙해지는 데 시간이 걸릴 수 있지만 모든 프로젝트 참여자가 모든 사람의 코드를 쉽게 읽고 이해할 수 있도록 스타일 규칙을 따르는 것이 중요합니다.

---

## 옮긴이 풀이

### 핵심: 형식 규칙은 임의적이지만, 모두가 같이 지키는 게 중요

코딩 스타일·형식 규칙은 다소 임의적입니다. 하지만 **모두가 같은 스타일**을 쓰면 코드를 훨씬 쉽게 읽고 따라갈 수 있습니다. 일부 규칙에 동의하지 않거나 익숙해지는 데 시간이 걸리더라도, 프로젝트의 모든 참여자가 서로의 코드를 쉽게 읽도록 규칙을 따르는 것이 중요합니다.

이 장의 하위 규칙들은 대부분 `clang-format` 같은 도구로 자동 적용할 수 있습니다.
