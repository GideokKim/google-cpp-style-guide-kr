# Google C++ Style Guide - 한글 번역

이 사이트는 [Google C++ Style Guide](https://google.github.io/styleguide/cppguide.html)의 한글 번역본입니다.

왼쪽 탐색 메뉴에서 원문의 주요 섹션과 하위 주제별 번역을 확인할 수 있습니다. 각 주제 페이지는 원문을 번역한 본문과 `이해하기 쉽게 설명하기` 섹션으로 구성되어 있습니다.
