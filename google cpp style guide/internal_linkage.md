# Internal Linkage (Internal Linkage)

## 원문 규칙 번역

.cc 파일의 정의를 해당 파일 외부에서 참조할 필요가 없는 경우 이름이 지정되지 않은 네임스페이스에 배치하거나 static 으로 선언하여 내부 연결을 제공하세요. .h 파일에서는 이러한 구성 중 하나를 사용하지 마세요.

모든 선언은 명명되지 않은 네임스페이스에 배치하여 내부 연결을 제공할 수 있습니다. 함수와 변수는 static 으로 선언하여 내부 연결을 제공할 수도 있습니다. 즉, 선언하는 내용은 다른 파일에서 액세스할 수 없습니다. 다른 파일이 동일한 이름을 가진 항목을 선언하는 경우 두 엔터티는 완전히 독립적입니다.

다른 곳에서 참조할 필요가 없는 모든 코드에는 .cc 파일의 내부 연결을 사용하는 것이 좋습니다. .h 파일에 내부 연결을 사용하지 마세요.

명명된 네임스페이스와 마찬가지로 명명되지 않은 네임스페이스의 형식을 지정합니다. 종료 주석에서 네임스페이스 이름을 비워 둡니다.

```cpp
namespace {
...
}  // namespace
```

## 이해하기 쉽게 설명하기

Internal Linkage 규칙을 적용할 때는 원문 규칙을 문자 그대로 외우기보다, 왜 이 선택이 독자에게 더 명확한지 살펴보면 쉽습니다. 코드 리뷰에서는 이 기능이 호출 지점에서 의도를 숨기지 않는지, 더 단순한 구조로 같은 목적을 달성할 수 없는지, 기존 코드와 섞였을 때 유지보수 비용이 커지지 않는지를 확인하세요.
