# 내부 연결 (Internal Linkage)

`.cc` 파일 안의 정의가 그 파일 밖에서 참조될 필요가 없다면, 이름 없는 네임스페이스에 넣거나 `static`으로 선언해 내부 연결을 부여하세요. 이 두 방법을 `.h` 파일에서 사용하지 마세요.

이름 없는 네임스페이스 안에 선언된 모든 이름은 내부 연결을 갖습니다. 함수와 변수는 `static`으로도 내부 연결을 가질 수 있습니다. 내부 연결을 가진 이름은 다른 파일에서 접근할 수 없고, 다른 파일에 같은 이름이 있어도 서로 완전히 독립적인 엔티티가 됩니다.

다른 곳에서 참조할 필요가 없는 `.cc` 파일의 코드는 내부 연결을 사용하는 것이 권장됩니다. 이름 없는 네임스페이스의 형식은 일반 네임스페이스와 비슷하게 쓰되, 닫는 주석에는 이름을 비워 둡니다.

```cpp
namespace {

void Helper() {
  // 이 파일에서만 사용하는 도우미 함수입니다.
}

}  // namespace
```

---

## 이해하기 쉽게 설명하기

내부 연결은 "이 파일 전용" 표시입니다. 도우미 함수가 다른 파일에서 쓰일 일이 없다면 굳이 전역 심볼로 노출하지 않는 것이 좋습니다. 이렇게 하면 같은 이름의 도우미 함수가 다른 파일에 있어도 충돌하지 않고, 독자도 그 함수의 사용 범위를 현재 파일 안으로 제한해 생각할 수 있습니다.

헤더는 여러 파일에 포함되므로 내부 연결 도구를 헤더에서 사용하면 각 번역 단위마다 별도의 복사본이 생겨 혼란을 만들 수 있습니다. 그래서 파일 전용 구현은 `.cc`에 두고, 헤더에는 공개해야 할 선언만 남기는 편이 안전합니다.
