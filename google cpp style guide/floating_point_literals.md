# 부동소수점 리터럴 (Floating-point Literals)

## 원문 규칙 번역

부동 소수점 리터럴은 지수 표기법을 사용하더라도 항상 양쪽에 숫자가 있는 기수 점이 있어야 합니다. 모든 부동 소수점 리터럴이 이 친숙한 형식을 취하면 가독성이 향상됩니다. 이는 정수 리터럴로 오인되지 않고 지수 표기법의 E/e가 16진수로 오인되지 않도록 하는 데 도움이 되기 때문입니다. 정수 리터럴로 부동 소수점 변수를 초기화하는 것은 괜찮지만(변수 유형이 해당 정수를 정확하게 나타낼 수 있다고 가정), 지수 표기법의 숫자는 결코 정수 리터럴이 아니라는 점에 유의하세요.

```cpp
float f = 1.f;
long double ld = -.5L;
double d = 1248e6;
```

```cpp
float f = 1.0f;
float f2 = 1.0;  // Also OK
float f3 = 1;    // Also OK
long double ld = -0.5L;
double d = 1248.0e6;
```

## 이해하기 쉽게 설명하기

이 규칙의 핵심은 이는 정수 리터럴로 오인되지 않고 지수 표기법의 E/e가 16진수로 오인되지 않도록 하는 데 도움이 되기 때문입니다.

실제로 코드를 볼 때는 부동 소수점 리터럴은 지수 표기법을 사용하더라도 항상 양쪽에 숫자가 있는 기수 점이 있어야 합니다.

점검할 때는 특히 다음을 확인하세요:

- 정수 리터럴로 부동 소수점 변수를 초기화하는 것은 괜찮지만(변수 유형이 해당 정수를 정확하게 나타낼 수 있다고 가정), 지수 표기법의 숫자는 결코 정수 리터럴이 아니라는 점에 유의하세요.
- 모든 부동 소수점 리터럴이 이 친숙한 형식을 취하면 가독성이 향상됩니다.
