# 이름 규칙의 예외 (Exceptions to Naming Rules)

## 원문 규칙 번역

기존 C 또는 C++ 엔터티(또는 상호 운용성을 통한 Rust 엔터티)와 유사한 이름을 지정하는 경우 기존 명명 규칙 체계를 따를 수 있습니다.

---

## 이해하기 쉽게 설명하기

이름 규칙의 예외 규칙을 적용할 때는 원문 규칙을 문자 그대로 외우기보다, 왜 이 선택이 독자에게 더 명확한지 살펴보면 쉽습니다. 코드 리뷰에서는 이 기능이 호출 지점에서 의도를 숨기지 않는지, 더 단순한 구조로 같은 목적을 달성할 수 없는지, 기존 코드와 섞였을 때 유지보수 비용이 커지지 않는지를 확인하세요.
