# 이름 규칙의 예외 (Exceptions to Naming Rules)

기존 C 또는 C++ 엔터티(또는 상호 운용성을 통한 Rust 엔터티)와 유사한 이름을 지정하는 경우 기존 명명 규칙 체계를 따를 수 있습니다.

---

## 옮긴이 풀이

### 핵심: 기존 엔터티를 흉내 낼 때는 그 규칙을 따라도 된다

기존 C/C++ 엔터티(또는 상호 운용을 위한 Rust 엔터티)와 비슷하게 보이도록 이름 짓는 경우에는, 이 가이드의 명명 규칙 대신 **그 기존 체계의 명명 규칙**을 따를 수 있습니다.

예를 들어 표준 컨테이너처럼 동작하는 타입을 만들 때 `begin()`, `end()`, `push_back()`처럼 표준 라이브러리 관습을 따르는 것이 자연스럽습니다.
