# 0과 nullptr/NULL (0 and nullptr/NULL)

## 원문 규칙 번역

포인터에는 nullptr을 사용하고 문자에는 '\0'을 사용합니다(0 리터럴은 아님).

포인터(주소 값)의 경우 유형 안전성을 제공하므로 nullptr을 사용하십시오.

널 문자에는 '\0'을 사용하십시오. 올바른 유형을 사용하면 코드를 더 쉽게 읽을 수 있습니다.

---

## 이해하기 쉽게 설명하기

0과 nullptr/NULL 규칙을 적용할 때는 원문 규칙을 문자 그대로 외우기보다, 왜 이 선택이 독자에게 더 명확한지 살펴보면 쉽습니다. 코드 리뷰에서는 이 기능이 호출 지점에서 의도를 숨기지 않는지, 더 단순한 구조로 같은 목적을 달성할 수 없는지, 기존 코드와 섞였을 때 유지보수 비용이 커지지 않는지를 확인하세요.
