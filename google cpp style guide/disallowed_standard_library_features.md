# 금지된 표준 라이브러리 기능 (Disallowed standard library features)

## 원문 규칙 번역

일부 최신 C++ 라이브러리 기능은 가독성을 저해하는 코딩 관행을 장려합니다. 예를 들어 독자에게 도움이 될 수 있는 확인된 중복성(예: 유형 이름)을 제거하거나 템플릿 메타프로그래밍을 장려하는 등의 방식입니다. 다른 확장 기능은 기존 메커니즘을 통해 사용할 수 있는 기능과 중복되므로 혼란과 전환 비용이 발생할 수 있습니다.

다음 C++ 표준 라이브러리 기능은 사용할 수 없습니다.

- 컴파일 시간 유리수( <ratio> )는 템플릿이 더 많은 인터페이스 스타일과 관련되어 있다는 우려 때문입니다.
- <cfenv> 및 <fenv.h> 헤더. 많은 컴파일러가 이러한 기능을 안정적으로 지원하지 않기 때문입니다.
- 테스트에 대한 지원이 충분하지 않고 고유한 보안 취약점을 겪고 있는 <filesystem> 헤더입니다.

## 이해하기 쉽게 설명하기

이 규칙의 핵심은 많은 컴파일러가 이러한 기능을 안정적으로 지원하지 않기 때문입니다.

실제로 코드를 볼 때는 - 컴파일 시간 유리수( <ratio> )는 템플릿이 더 많은 인터페이스 스타일과 관련되어 있다는 우려 때문입니다.

점검할 때는 특히 다음을 확인하세요:

- 다른 확장 기능은 기존 메커니즘을 통해 사용할 수 있는 기능과 중복되므로 혼란과 전환 비용이 발생할 수 있습니다.
- - 테스트에 대한 지원이 충분하지 않고 고유한 보안 취약점을 겪고 있는 <filesystem> 헤더입니다.
