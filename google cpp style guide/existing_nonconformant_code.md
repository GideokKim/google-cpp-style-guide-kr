# 기존 비준수 코드 (Existing Non-conformant Code)

## 원문 규칙 번역

이 스타일 가이드를 따르지 않는 코드를 다룰 때 규칙에서 벗어날 수 있습니다.

이 가이드에 제시된 사양과 다른 사양으로 작성된 코드를 수정하는 경우 해당 코드의 지역 규칙과 일관성을 유지하기 위해 이러한 규칙에서 벗어나야 할 수도 있습니다. 이를 수행하는 방법에 대해 의문이 있는 경우 원저작자 또는 현재 코드 책임자에게 문의하십시오. 일관성에는 로컬 일관성도 포함된다는 점을 기억하세요.

---

## 이해하기 쉽게 설명하기

기존 비준수 코드 규칙을 적용할 때는 원문 규칙을 문자 그대로 외우기보다, 왜 이 선택이 독자에게 더 명확한지 살펴보면 쉽습니다. 코드 리뷰에서는 이 기능이 호출 지점에서 의도를 숨기지 않는지, 더 단순한 구조로 같은 목적을 달성할 수 없는지, 기존 코드와 섞였을 때 유지보수 비용이 커지지 않는지를 확인하세요.
