# 템플릿 매개변수 이름 (Template Parameter Names)

템플릿 매개변수는 해당 카테고리의 이름 지정 스타일을 따라야 합니다. 유형 템플릿 매개변수는 유형 이름 지정 규칙을 따라야 하며, 비유형 템플릿 매개변수는 변수 또는 상수 이름 지정 규칙을 따라야 합니다.

---

## 옮긴이 풀이

### 핵심: 해당 카테고리 규칙을 따른다

템플릿 매개변수는 그 종류에 맞는 명명 규칙을 따릅니다.

- **타입 템플릿 매개변수** → 타입 이름 규칙(PascalCase). 예: `T`, `ElementType`.
- **비타입(non-type) 템플릿 매개변수** → 변수 또는 상수 이름 규칙.
