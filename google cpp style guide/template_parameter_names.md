# 템플릿 매개변수 이름 (Template Parameter Names)

## 원문 규칙 번역

템플릿 매개변수는 해당 카테고리의 이름 지정 스타일을 따라야 합니다. 유형 템플릿 매개변수는 유형 이름 지정 규칙을 따라야 하며, 비유형 템플릿 매개변수는 변수 또는 상수 이름 지정 규칙을 따라야 합니다.

---

## 이해하기 쉽게 설명하기

템플릿 매개변수 이름 규칙을 적용할 때는 원문 규칙을 문자 그대로 외우기보다, 왜 이 선택이 독자에게 더 명확한지 살펴보면 쉽습니다. 코드 리뷰에서는 이 기능이 호출 지점에서 의도를 숨기지 않는지, 더 단순한 구조로 같은 목적을 달성할 수 없는지, 기존 코드와 섞였을 때 유지보수 비용이 커지지 않는지를 확인하세요.
