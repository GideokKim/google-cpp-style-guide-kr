# 클래스 (Classes)

클래스는 C++ 코드의 기본 단위이며, 당연히 우리는 클래스를 광범위하게 사용합니다. 이 섹션에는 클래스를 작성할 때 따라야 할 것과 하지 말아야 할 것이 정리되어 있습니다.

---

## 옮긴이 풀이

클래스는 C++ 코드의 기본 구성 단위입니다. 이 장의 하위 규칙들은 클래스를 설계할 때 반복적으로 부딪히는 결정들 — 생성자에서 무엇을 할지, 암시적 변환을 허용할지, 복사·이동을 어떻게 노출할지, struct와 class 중 무엇을 쓸지, 상속을 쓸지, 멤버를 어떻게 숨길지 — 을 다룹니다.

관통하는 원칙은 하나입니다: **클래스의 공개 인터페이스만 보고도 그 클래스를 어떻게 안전하게 쓸 수 있는지 분명해야 한다.** 숨은 전제나 예상치 못한 비용(암시적 변환, 값 복사, 생성자 실패 등)을 독자에게 떠넘기지 않는 것이 핵심입니다.
