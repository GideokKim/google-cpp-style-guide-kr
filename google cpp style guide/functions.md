# 함수 (Functions)

이 장은 함수를 설계할 때의 규칙을 다룹니다. 입력과 출력의 표현, 함수 길이, 오버로딩, 기본 인자, 후행 반환 타입처럼 호출 지점과 선언부에서 함수의 계약이 드러나는 방식을 각 하위 주제에서 설명합니다.

---

## 옮긴이 풀이

함수 규칙은 호출자가 함수의 계약을 한눈에 이해하도록 만드는 데 초점이 있습니다. 원문은 입력과 출력, 함수 길이, 오버로딩, 기본 인자, 후행 반환 타입처럼 호출 지점과 선언부에서 드러나는 단서를 다룹니다.

실무에서는 "함수 이름과 시그니처만 보고 무엇을 읽고 무엇을 바꾸는지 알 수 있는가?"를 먼저 확인하세요. 숨은 출력, 과도한 오버로딩, 긴 함수 본문은 모두 호출자의 추론 비용을 키웁니다.

점검할 때는 특히 다음을 확인하세요:

- 입력과 출력 방향이 매개변수 타입에서 드러나는가?
- 함수가 너무 길어져 여러 책임을 섞고 있지 않은가?
- 오버로딩이나 기본 인자가 호출 의미를 흐리지 않는가?
